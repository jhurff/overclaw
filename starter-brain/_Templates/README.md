# _Templates

Blank templates for common vault files.

## What's here

| Template | Use it for |
|---|---|
| `BOOTSTRAP-template.md` | First-run context for a brand new agent |
| `SOUL-template.md` | Agent identity and personality |
| `AGENTS-template.md` | Agent operating instructions |
| `MEMORY-template.md` | Agent long-term memory (starts empty) |
| `USER-template.md` | About the human (filled in over time) |
| `task-template.md` | Individual task files in `03 - Agents/Coordination/Tasks/` |
| `project-template.md` | New project folder README |
| `weekly-review-template.md` | Weekly summary note |

## How to use

Copy the relevant template to its destination and fill it in.
Do not edit the templates themselves unless you want to change the default
format for everyone.

```bash
cp "_Templates/SOUL-template.md" /path/to/agent/workspace/SOUL.md
```
