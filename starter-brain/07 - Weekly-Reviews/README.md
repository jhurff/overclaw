# 07 - Weekly Reviews

Weekly summary notes from your swarm.

## Purpose

Every week the swarm produces a brief summary: what got done, what's
in progress, what's blocked, what needs a decision. This folder holds
those summaries.

Weekly reviews serve two purposes:

1. **Accountability** — a clear record of what happened week by week
2. **Continuity** — new agent sessions can read recent reviews and
   get up to speed without reading every task file

## What belongs here

- One file per week, named by week-ending date: `2026-W01.md`
- Generated by the ops agent, usually Monday morning
- Should take 2 minutes to read, not 20

## File naming

```
YYYY-WNN.md       (e.g. 2026-W01.md for the week ending Jan 4, 2026)
```

## Review format

Each review file should cover:

- ✅ Completed last week
- 🔄 In progress this week
- 🔴 Blocked (needs human input)
- 📋 Inbox backlog
- 💡 One insight or lesson from the week

Keep it to one page. If it's longer than that, it's a log, not a review.
