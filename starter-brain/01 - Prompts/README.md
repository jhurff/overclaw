# 01 - Prompts

Reusable prompt templates for your agents.

## Purpose

Instead of writing the same instructions from scratch every time, store
prompt templates here. Agents reference them by name. You evolve them
over time as you learn what works.

Good prompts are an asset. A prompt that reliably produces the right
output is worth keeping, naming, and improving.

## What belongs here

- System prompt templates (e.g. "how to write a task brief")
- Recurring task prompts (e.g. "weekly review format")
- Prompt snippets that get reused across multiple agents or workflows
- Notes on what worked, what didn't, and why

## Naming convention

Use descriptive names. Prefix with the domain if helpful:

```
research-summarize-article.md
writing-draft-blog-post.md
ops-create-task-brief.md
review-weekly-summary.md
```

## Tips

- Version prompts when you make significant changes (append `-v2`, `-v3`)
- Leave a short note at the top of each prompt explaining when to use it
- Archive prompts that no longer work rather than deleting them
