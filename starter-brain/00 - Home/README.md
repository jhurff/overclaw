# 00 - Home

The front door of your AI Brain. Start here.

## Purpose

This folder holds the documents your agents and you return to most often:
the vault index, onboarding notes, and any pinned reference material that
doesn't belong anywhere else.

Think of it as the lobby. Everything important should be reachable from here
within one or two hops.

## What belongs here

- `VAULT-INDEX.md` — a map of what's in the vault and where to find it
- `ONBOARDING.md` — how to get a new agent up to speed fast
- `CONVENTIONS.md` — naming conventions, date formats, status labels
- Pinned reference docs you want every agent to see first

## What doesn't belong here

Active task work, research notes, and project files all belong in their
own numbered folders. Keep this folder light.
