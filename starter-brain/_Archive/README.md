# _Archive

Completed projects, retired agents, and old files — kept for reference.

## Purpose

Nothing gets deleted. Things that are done or no longer active get moved here.

The archive is the vault's long-term memory for completed work. Future agents
can read it to understand decisions that were made, approaches that were tried,
and context that no longer needs to be front-of-mind.

## What belongs here

- Completed project folders (from `02 - Projects/`)
- Retired agent workspace files
- Old versions of documents that were significantly revised
- Research notes that are no longer relevant but might be useful someday

## What doesn't belong here

- Active tasks or projects
- Files you're still referencing regularly
- Anything an agent needs to do current work

## Naming convention

When you move something here, prefix it with the date it was archived:

```
_Archive/
├── 2026-01-15-example-project/
└── 2026-02-01-old-agent-workspace/
```

## Pruning

The archive can grow large over time. Periodically review it and delete
things that are truly no longer useful. When in doubt, keep it — storage
is cheap, context is valuable.
